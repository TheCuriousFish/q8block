# Q8block - Digital Marketing Agency Website

A modern, bilingual (Arabic/English) website for Q8block, a digital marketing agency in Kuwait.

## Features

- **Bilingual Support**: Arabic (RTL) and English (LTR) versions
- **Modern Design**: Advanced aesthetics with smooth animations
- **Responsive**: Fully responsive design for all devices
- **Performance**: Optimized for fast loading
- **SEO Ready**: Proper meta tags and semantic HTML

## Services Showcased

- Google Ads Management
- Meta (Facebook/Instagram) Ads
- Search Engine Optimization (SEO)
- Instagram Management
- Website Design & Development
- Analytics & Reporting

## Tech Stack

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- Vanilla JavaScript (ES6+)
- No frameworks or dependencies

## Structure

```
q8block/
├── index.html          # Arabic homepage (RTL)
├── styles.css          # Main stylesheet
├── styles-en.css       # English-specific overrides
├── script.js           # JavaScript functionality
├── en/
│   └── index.html      # English homepage (LTR)
├── assets/
│   ├── icons/
│   │   └── favicon.svg
│   └── images/
└── logos/              # Partner/tool logos
```

## Design Principles

Based on Alex Hormozi's marketing principles:
- Clear value proposition
- Problem-agitation-solution framework
- Strong calls-to-action
- Social proof through testimonials
- Risk reversal with free consultation offer

## Brand Colors

- Primary: `#7ed321` (Lime Green)
- Secondary: `#00d4aa` (Teal)
- Dark: `#0a1628` (Navy)
- Accent: `#ff6b6b` (Coral)

## Getting Started

Simply open `index.html` in a browser or deploy to any static hosting service.
