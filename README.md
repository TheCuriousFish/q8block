# Q8Block - AI-Optimized Digital Marketing Agency

A modern, responsive website for Q8Block, a leading digital marketing agency based in Kuwait, specializing in AI search optimization, SEO, Google Ads management, and web development.

## 🌟 Features

- **AI-First Approach**: Optimized for AI-powered search engines (ChatGPT, Gemini, etc.)
- **Modern Design**: Inspired by premium web design trends with bold colors and smooth animations
- **Fully Responsive**: Mobile-first design that works perfectly on all devices
- **Lightning Fast**: Hand-coded HTML/CSS/JS with no frameworks for optimal performance
- **Smooth Animations**: Lightweight CSS and JavaScript animations for engaging user experience
- **SEO Optimized**: Clean semantic HTML structure for better search engine visibility

## 🎨 Design

The website features a modern, professional design with:
- Navy blue and cyan color scheme (inspired by oakharborwebdesigns.com)
- Bold typography with Inter font family
- Smooth scroll animations and micro-interactions
- Diagonal wave sections for visual interest
- 3D mockup elements in hero section
- Card-based layouts for services and testimonials

## 🚀 Technologies

- **HTML5**: Semantic markup
- **CSS3**: Modern CSS with custom properties, Grid, and Flexbox
- **JavaScript**: Vanilla JS for animations and interactivity
- **No Dependencies**: Zero external libraries for maximum performance

2. Set build command: (none - static site)
3. Set publish directory: `/`
4. Deploy from `production` branch
